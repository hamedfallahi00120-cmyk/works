# اتصال سنسورهای سخت‌افزار به Local Office AI

## وضعیت اتصال

پنل پایش Local Office AI اطلاعات را از منابع زیر دریافت می‌کند:

- مصرف CPU و RAM: `psutil`
- اطلاعات GPU انویدیا (در صورت وجود): `nvidia-smi`
- اطلاعات GPU AMD در ویندوز و دمای CPU/GPU: REST API محلی LibreHardwareMonitor
- URL پیش‌فرض: `http://127.0.0.1:8085/data.json`

در ویندوز، Local Office AI داده‌های سنسور را با یک درخواست HTTP محلی می‌خواند؛ به WMI یا کتابخانه Python دیگری نیاز ندارد. پاسخ API در هر نمونه‌برداری یک‌بار خوانده و برای CPU و GPU مشترک استفاده می‌شود.

برای سیستم مورد استفاده، نام سخت‌افزارها به این صورت تشخیص داده می‌شود:

- CPU: `13th Gen Intel Core i5-13400`، سنسور ترجیحی `CPU Package`
- GPU: `Radeon RX 580 Series`، سنسور ترجیحی دما `GPU Core`

در صورت وجود سنسورهای Load و Memory، درصد فعالیت GPU و حافظه مصرف‌شده/کل نیز خوانده می‌شوند. اگر هر سنسور موجود نباشد، همان مقدار «در دسترس نیست» نمایش داده می‌شود؛ هیچ مقدار صفر یا تخمینی جایگزین نمی‌شود.

## لازم است LibreHardwareMonitor همیشه باز باشد؟

پنجره آن لازم نیست باز بماند، اما **فرایند LibreHardwareMonitor باید در پس‌زمینه در حال اجرا باشد** تا دما در دسترس بماند.

برای تنظیم یک‌باره:

1. LibreHardwareMonitor را با دسترسی Administrator اجرا کنید.
2. از منوی `Options`، گزینه `Remote Web Server > Run` را فعال کنید؛ پورت پیش‌فرض `8085` باقی بماند.
3. در صورت وجود انتخاب IP، فقط `127.0.0.1` یا `localhost` را انتخاب کنید؛ سرور سنسورها را روی شبکه عمومی در دسترس نگذارید.
4. در منوی `Options`، گزینه‌های `Run On Windows Startup`، `Start Minimized` و `Minimize To Tray` را فعال کنید. در صورت وجود `Minimize On Close` را نیز فعال کنید.
5. پس از این تنظیم، می‌توانید پنجره را به سینی سیستم کوچک کنید. Local Office AI داده‌ها را از همان سرویس محلی می‌خواند.

اگر LibreHardwareMonitor کاملاً بسته شود یا سرور Remote Web Server متوقف شود، دمای CPU و GPU «در دسترس نیست» می‌شود؛ تحلیل Excel و Ollama همچنان کار می‌کنند.

## رفتار پنل

- نمونه‌برداری فقط وقتی پنل داخلی یا ویجت شناور قابل مشاهده است انجام می‌شود.
- با بستن پنل، نمونه‌برداری Local Office AI متوقف می‌شود.
- اطلاعات سخت‌افزار فقط برای نمایش رابط هستند و هرگز وارد فایل Excel خروجی نمی‌شوند.
- این تنظیمات هیچ وابستگی جدید Python نصب نمی‌کنند.
