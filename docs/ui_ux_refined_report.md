# گزارش کوتاه بازطراحی رابط — Local Office AI

نسخه: `Local-Office-AI_UI_UX_Refined`
دامنه کار: فقط لایه رابط PySide6. موتور تحلیل، محاسبات `Decimal`، استخراج فایل و ساخت گزارش Excel
تغییر نکرده است و هیچ Sheet، ستون یا فایل خروجی جدیدی اضافه نشده است.

## ۱) فایل‌های تغییرکرده

| فایل | تغییر |
|---|---|
| `theme.py` | پالت روشن/تیره، QSS دکمه‌ها، فیلدها، جدول‌ها، تب‌ها، چیپ‌ها، فاصله‌ها؛ حذف استایل دستی `::indicator` چک‌باکس |
| `components.py` | `Card`، `SectionHeader`، `Badge`، `MetricTile`، `NavigationButton`، `EmptyState`، `BarChart`، هِلپرهای `form_row()` و `horizontal_line()` |
| `chrome.py` | Sidebar بخش‌بندی‌شده و جمع‌شونده، TopBar، HardwarePanel، StatusBar |
| `icons.py` | آیکون‌های `monitor` و `sidebar` و یکسان‌سازی اندازه |
| `source.py` | `SourceListCard` (جدول منابع + حذف ردیف + شمارش) و `RequestComposer` (کادر درخواست، چیپ پیشنهاد، دکمه شروع) |
| `pages/home.py` | چیدمان تازه صفحه خانه (معرفی، منابع، درخواست، آخرین نتیجه) |
| `pages/file_analysis.py` | استفاده از کارت منابع مشترک و هدر یکسان |
| `pages/folder_analysis.py` | هدر/متن راهنما و هم‌ترازی با بقیه صفحات |
| `pages/chat.py` | حباب پیام راست‌چین، چیپ پیشنهاد، کادر و دکمه ارسال |
| `pages/settings.py` | فرم تنظیمات با `form_row` (برچسب راست، کنترل چپ) |
| `results.py` | ترتیب بج/عنوان در کارت‌های پاسخ، خوانایی تب‌ها |
| `main_window.py` | اتصال سیگنال‌ها، اسکن پوشه در Worker، حذف انیمیشن opacity، رفع باگ «پاک کردن فهرست» |
| `formatting.py` | هِلپر `rtl()` و `align_table_header()` برای تراز درست جدول‌ها |
| `app.py` | بارگذاری ترجمهٔ فارسی خود Qt (`qtbase_fa`) برای دیالوگ‌های داخلی |
| `ui_settings.py` + `config/ui_settings.json` | اندازه پیش‌فرض متن ۱۳pt |
| `AGENTS.md` | مستندسازی ساختار لایه UI و قاعده «افکت گرافیکی روی کارت‌ها ممنوع» |

## ۲) ایرادهای گرافیکی اصلاح‌شده

1. **مستطیل‌های تیره و خالی** (تصویر ارسالی): علت، `QGraphicsDropShadowEffect` / `QGraphicsOpacityEffect`
   روی کارت‌ها و صفحات بود. روی ویندوز این افکت‌ها به‌جای سایه، یک لایه مشکی توپر روی محتوا می‌کشند.
   همه افکت‌ها و انیمیشن‌های opacity صفحه حذف شد؛ محتوا با Layout واقعی و رنگ پالت رندر می‌شود.
   این رفع، ریشه‌ای است، نه پنهان‌سازی: در تصاویر تست، فیلدها متن و قاب درست دارند.
2. **کارت‌های تزئینی و تکرار انتخاب منبع**: انتخاب منبع در خانه/تحلیل فایل/تحلیل پوشه تکرار می‌شد؛
   حالا یک کارت مشترک `SourceListCard` در همه‌جا استفاده می‌شود.
3. **جدول منابع**: نام فایل / نوع / وضعیت، حذف تکی، شمارش منابع، «پاک کردن فهرست»، و مسیر کامل فقط
   به‌صورت tooltip (بدون دراز کردن ردیف).
4. **بج‌ها و عنوان‌ها**: در کارت‌های پاسخ و «آخرین نتیجه»، بج کنار عنوان قرار گرفت (نه انتهای سطر).
5. **چک‌باکس**: قبلاً مربع پر بدون تیک بود؛ حالا تیک واقعی و واضح در هر دو تم.
6. **دکمه‌ها**: یک Design System (`Primary` / `Ghost` / `Quiet` / `DangerQuiet` / `IconButton`) با
   ارتفاع، padding و حالت hover/focus/disabled یکسان.
7. **عبارت‌های انگلیسی در پنجره‌های سیستمی**: ترجمهٔ فارسی خود Qt بارگذاری می‌شود، بنابراین
   «New folder» به «پوشه جدید»، «OK/Cancel» به «تأیید/انصراف» و سایر برچسب‌های
   `QFileDialog`/`QMessageBox` فارسی می‌شوند (اگر ویندوز دیالوگ بومی را نشان دهد، زبان سیستم حاکم است).
8. **مسیر خروجی**: در صفحات تحلیل فایل و تحلیل پوشه، زیر کادر درخواست نوشته می‌شود
   «خروجی: data/output • فایل‌های ورودی تغییر نمی‌کنند» تا کاربر بداند نتیجه کجا ذخیره می‌شود
   (مسیر کامل در tooltip).
9. **پنجره‌های کم‌ارتفاع**: زیر ۸۲۰ پیکسل ارتفاع، خط توضیحی معرفی در صفحهٔ خانه جمع می‌شود تا
   دکمهٔ «شروع تحلیل» بدون اسکرول در دسترس باشد (۱۳۶۶×۷۶۸ آزمایش شد).

## ۳) Typography

- اندازه متن عادی: **۱۳pt** (پیش‌فرض جدید، قابل تغییر در تنظیمات)، عنوان بخش‌ها: **۱۹pt**،
  عنوان اصلی صفحه ۲۴–۲۸pt و توضیحات کوچک‌تر با حداقل خوانایی.
- فونت انتخاب‌شده در تنظیمات روی `QApplication` و سپس روی QSS اعمال می‌شود و در هر تغییر تم یا
  تغییر اندازه دوباره اعمال می‌گردد؛ بنابراین همه ویجت‌ها (جدول، تب، دکمه، tooltip) همان فونت را دارند.
- جهت متن: برنامه RTL، ورودی فارسی راست‌چین، مسیرها و نام‌های فنی با `ltr()` و هدر جدول‌ها با
  `align_table_header()` تراز می‌شوند تا اعداد و پرانتزها جابه‌جا نشوند.

## ۴) Sidebar

- ساختار سه‌بخشی: هویت برنامه (آیکون، نام، نسخه) / فضای کار (خانه، تحلیل فایل‌ها، تحلیل پوشه،
  گفت‌وگوی هوشمند، گزارش‌های قبلی) / سیستم (تنظیمات).
- ردیف آیکون+عنوان با Layout واقعی (نه rich-text) تا در هر عرضی تراز بماند؛ آیکون‌ها هم‌اندازه.
- صفحه فعال با پس‌زمینه ملایم و متن برجسته مشخص است.
- دکمه جمع‌کردن: ریل ۶۸ پیکسلی با آیکون و tooltip؛ در ۱۳۶۶×۷۶۸ هم چیزی بریده نمی‌شود.

## ۵) پایداری

- اسکن پوشه از حلقه UI خارج شد و در Worker اجرا می‌شود؛ رابط هنگام اسکن و تحلیل پاسخ می‌دهد.
- انیمیشن‌های fade صفحه حذف شد (علت اصلی flicker و مستطیل مشکی).
- Timer/Worker پایش سخت‌افزار تک‌نمونه است و فقط با باز بودن پنل نمونه می‌گیرد؛ پنل شناور همان
  `HardwareWorker` موجود را استفاده می‌کند (سنسور دوم اضافه نشده).
- به‌روزرسانی ویجت‌ها فقط از طریق سیگنال به رشته اصلی انجام می‌شود.
- رفع باگ: دکمه «پاک کردن فهرست» واقعاً فهرست منابع را خالی می‌کند (قبلاً فقط پیام می‌داد).
- بررسی واقعی: تحلیل یک فایل ۲۹ ثانیه طول کشید و در همین مدت جابه‌جایی بین صفحات خانه، فایل،
  گفت‌وگو و گزارش‌ها بدون توقف انجام شد؛ نتیجه و فایل Excel هم تولید شد.

## ۶) وضعیت قابلیت‌های قبلی

همه قابلیت‌ها سرجای خود هستند: Excel، تحلیل چندفایلی، پوشه و زیرپوشه، Word، PowerPoint، PDF، CSV،
TXT، OCR فارسی، Ollama/Qwen، گفت‌وگوی هوشمند، تاریخچه گزارش‌ها، انتخاب فونت، تم روشن/تیره،
پایش CPU/RAM/GPU، دمای CPU و RX 580 از LibreHardwareMonitor، پنل شناور و System Tray.
فایل خروجی Excel و منطق موتور دست‌نخورده است؛ فایل‌های کاربر خوانده و بازنویسی نمی‌شوند.
